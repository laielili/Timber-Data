---

## 0. 设计原则

1. **自顶向下**：先定指标目标值，再倒推数据——不是"先造数据再算指标"。
2. **恒等式优先**：`M0 = 平均单位价值 × 处理率 − 平均单位成本` 必须**精确成立**（分位级），示例数据才有教学价值。
3. **池预算先行**：先生成状态池（Output / In Progress / Pending / Unresolved）的吨数预算，再排布到批次与物料。
4. **每个指标一个叙事**：所有目标值必须能被一句话解释（面试可讲）。
5. **全程 Demo 标注**：生成数据与文档数值均标注为合成原型。

## 1. 目标画像（指标 → 目标值）

| 链节 | 目标值 | 恒等式角色 | 叙事 |
|---|---|---|---|
| M0 净回收价值/入库t | **70.00 AUD/t**（净额 86,800） | 北极星 | 每吨入库赚 70 元 |
| 入库（总量） | **1,240 t** / 36 批次 / 16 来源 / 12 月 | 分母 | 与现有规模一致 |
| M3.1 处理率 | **80.0%**（处理 992 t） | 乘数 | 五吨进、四吨出 |
| M3.3 在途率 | **18.0%**（223.2 t = In Progress 155 + Pending 68.2） | 快照 | Q4 未闭环 |
| M3.2 未决率 | **2.0%**（24.8 t） | 快照 | 高不确定来源定级失败 |
| M1.2 平均单位价值 | **320.00 AUD/处理t**（价值总额 317,440） | 加数 | 等级结构反解 |
| M2.2 平均单位成本 | **186.00 AUD/入库t**（Core-5 总额 230,640） | 减数 | 成本结构反解 |

**恒等式验证（设计目标，分位级精确）：**

```
平均单位价值 320.00 × 处理率 80.00% − 平均单位成本 186.00 = 70.00 AUD/t
价值总额 317,440 − 成本总额 230,640 = 净额 86,800
净额 86,800 ÷ 入库 1,240 = 70.00 ✓
```

## 2. 时间与批次骨架

- 期间：2025-01-01 ~ 2025-12-31；快照：`as_of = 2025-12-31T18:00:00`；对比期：Dec vs Nov。
- 36 批次：1–9 月每月 3 批全部闭环；**Q4（10–12 月）6 批未闭环**，构成转化端叙事。
- 批次状态：
  - **30 批 Completed（Realised）**：合计 992 t 全量输出——正式经济比较的唯一集合。
  - **6 批 Partially Completed（Provisional）**：合计 248 t 未闭环——In Progress 2 批（155 t）、Pending 2 批（68.2 t）、Unresolved 2 批（24.8 t），零输出。
- 叙事：Q4 高不确定性采购（Direct Salvage Purchase / Residential Demolition）集中到货，年末留下在途与未决。

## 3. 价值端设计（S1）

### 3.1 等级单价（assumptions 整数化）

| 等级 | 单价 AUD/t |
|---|---|
| Premium | 650 |
| Character | 450 |
| Rustic | 280 |
| Feedstock | 125 |

### 3.2 最终等级结构（由"平均单位价值 = 320"反解）

| 等级 | 吨数 | 价值 AUD | 占比 |
|---|---:|---:|---:|
| Premium | 175 | 113,750 | 17.6% |
| Character | 199 | 89,550 | 20.1% |
| Rustic | 238 | 66,640 | 24.0% |
| Feedstock | 380 | 47,500 | 38.3% |
| **合计** | **992** | **317,440** | 100% |

反解约束：`650P + 450C + 280R + 125F = 317,440`，`P+C+R+F = 992`（整数吨）。

### 3.3 路线映射与价值（HV 率 = 35.7%）

| 路线 | 构成 | 吨数 | 价值 AUD |
|---|---|---:|---:|
| Higher-value Recovery | Premium 175 + Character 179 | 354 | 194,300 |
| Board Feedstock | Rustic 238 + Feedstock 308 | 546 | 105,140 |
| Special Handling | Character 20 + Feedstock 28 | 48 | 12,500 |
| Residual / Disposal | Feedstock 44 | 44 | 5,500 |
| **合计** | | **992** | **317,440** |

- HV 率 = 354 ÷ 992 = **35.7%**（设计目标）
- 等级结构按来源画像分层：Infrastructure Salvage → HV ~60%；Residential Demolition → HV ~22%（保留现有分层故事，逐来源生成时校验）

### 3.4 降级设计（降级率 = 7.06%）

| 初始等级 | 吨数 | 降级去向 | 最终等级 |
|---|---:|---|---|
| Premium | 175 | — | 175 |
| Character | 231 | 32 → Rustic | 199 |
| Rustic | 244 | 38 → Feedstock（另 +32 来自 Character） | 238 |
| Feedstock | 342 | —（另 +38） | 380 |
| **合计** | **992** | 降级 70 t | 992 |

降级率 = 70 ÷ 992 = **7.06%**（设计目标 ~7%）。

## 4. 成本端设计（S2）

### 4.1 Core-5 目标总额（合计精确 = 230,640）

| 成本类别 | 目标总额 AUD | 率 | 率的口径 | 占比 |
|---|---:|---|---|---:|
| Processing | 103,596 | 104.43 AUD/处理t | 处理吨（992） | 44.9% |
| Sorting Labour | 66,960 | 54.00 AUD/入库t | 入库吨（1,240） | 29.0% |
| Inspection | 52,080 | 42.00 AUD/入库t | 入库吨（1,240） | 22.6% |
| Special Handling | 5,760 | 120.00 AUD/SH吨 | SH 路线吨（48） | 2.5% |
| Disposal | 2,244 | 51.00 AUD/残渣吨 | 残渣路线吨（44） | 1.0% |
| **合计** | **230,640** | | | 100% |

- 结构叙事：处理 45% / 分拣 29% / 检验 22.5% / 特殊处理 2.5% / 处置 1%（取整后）。
- 明确排除 Transport / Other（与 `metric_system.md` §3.2 一致）。

### 4.2 归属规则（方案 B：状态专属成本强度）★ 用户已确认

| 成本类别 | 归属方式 |
|---|---|
| Sorting Labour + Inspection（96.00 AUD/t） | **按状态重量摊分**（1,240 t 全覆盖，每状态各背 96.00/t） |
| Processing（104.43 AUD/t） | **仅 Output**（992 t） |
| Special Handling / Disposal | **仅 Output** 中对应路线吨 |

由此得到矩阵的确定性结构：**任何非 Output 吨固定亏损 96.00 AUD/t**（分拣+检验已沉没），Output 吨背全栈。

## 5. 转化端设计（S3）——状态池与矩阵

### 5.1 状态池预算（快照 as_of）

| 状态池 | 吨数 | 批次 | 叙事 |
|---|---:|---:|---|
| Output | 992.0 | 30 Completed（全量输出） | 全栈成本，全量价值 |
| In Progress | 155.0 | 2 批处理中（B030 80 + B034 75） | 检验 96.0 + 处理中 59.0 |
| Pending Processing | 68.2 | 2 批待排产（B032/B035，各 34.1） | 处于分拣排队（Sorting 桶） |
| Unresolved | 24.8 | 2 批定级失败（B033/B036，各 12.4） | 高不确定来源，检验后仍无法定级 |
| **合计** | **1,240.0** | 36 批 | |

在途率 = (155 + 68.2) ÷ 1,240 = 18.0%；未决率 = 24.8 ÷ 1,240 = 2.0%。

### 5.2 快照积压桶（Operational Backlog 图，互斥）

| 积压桶 | 吨数 |
|---|---:|
| Unresolved | 24.8 |
| Inspection（在检） | 96.0 |
| Sorting（排队分拣） | 68.2 |
| Processing（处理中） | 59.0 |
| **合计** | **248.0** |

### 5.3 状态 × 净价值矩阵（方案 B 归属，设计值）

| 状态 | 吨数 | 归属成本 AUD | 归属价值 AUD | 净贡献 AUD | 每状态吨净 AUD |
|---|---:|---:|---:|---:|---:|
| Output | 992.0 | 206,832.00 | 317,440.00 | **+110,608.00** | **+111.50** |
| In Progress | 155.0 | 14,880.00 | 0 | −14,880.00 | −96.00 |
| Pending | 68.2 | 6,547.20 | 0 | −6,547.20 | −96.00 |
| Unresolved | 24.8 | 2,380.80 | 0 | −2,380.80 | −96.00 |
| **合计** | **1,240.0** | **230,640.00** | **317,440.00** | **+86,800.00** | **+70.00** |

- Output 行：992 × 96.00 + 103,596 + 5,760 + 2,244 = 206,832 ✓
- 合计自洽：行和 = 列和；净额 = 86,800 = 70.00 × 1,240 ✓

**矩阵叙事（面试可讲）：**
> 未闭环的每一吨已经花掉 96 元分拣+检验钱而没有任何产出；已输出的每一吨净赚 111.50 元。
> 提升北极星只有三条路：把吨从 −96 池移进 +111.50 池（S3）、压低 96.00 的两项成本率（S2）、抬高等级结构到 320 以上（S1）。

## 6. 对比期与趋势叙事

- **来源分层**：6 类来源的 HV 率、每吨价值、每吨成本形成可预期的梯度（Infrastructure Salvage 最优 → Residential Demolition 最差），供"来源结构"图与批次象限图呈现。
