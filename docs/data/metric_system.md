# METRIC SYSTEM — 净回收价值（North Star）指标体系

> 版本：v1.0（2026-08-20）　2026-08-20 修订：§4.2 归属规则版本化为方案 B；§4.3 矩阵换为设计目标值
> 定位：本文件是**指标体系的"设计层"**——用 OSM 框架说明指标为什么存在、彼此如何相关；
> 每个指标的详细算法见 `METRIC_DICTIONARY.md`，时间基准规范见 `TIME_SEMANTICS.md`。
> 数值基准：**目标值 = `sample_data_design.md`**（净回收价值链 70.00 AUD/t）；`workbench.db`（seed 20260820）为实施载体。
> 所有数值为合成原型数据，非行业真实数据。

## 0. 目的与边界（一次只分析一个目的）

**本文件的唯一目的：回答"每吨入库木材的净回收价值从哪里来、如何提高"。**

- 指标体系的其余目的（记录质量、批次周转、积压桶明细、风险监控等）**不进入本链**；
  需要时各自单独立 OSM 链，引用 `METRIC_DICTIONARY` 中的对应字典条目，但不同时混入。
- 本链内指标是**封闭的**：要么是北极星的加性成分，要么是恒等式中的驱动比，不允许出现与北极星无关的指标。
- 未来新增分析目的时，重复本文件的骨架（目的 → O/S/M → 恒等式 → 维度切片），保持每份文件一次只回答一个问题。

## 1. OSM 总框架

| 层                          | 内容                                                                         | 指标                    | 构成                                                       |
| --------------------------- | ---------------------------------------------------------------------------- | ----------------------- | ---------------------------------------------------------- |
| **O1 目标**           | 提升每入库吨的净回收价值（设计基线**70.00 AUD/t**）                    | **M0 北极星**     | 净回收价值 / 入库吨（AUD/t，期间）                         |
| **S1 策略·价值创造** | 让每一吨已处理木材卖出更高价值：等级结构上移、高价值路线占比提升、降级控制   | **M1 价值端度量** | 回收价值总额、平均单位价值、HV 率、降级率、等级结构占比    |
| **S2 策略·成本效率** | 让每一吨入库木材消耗更低的核心回收成本：分拣 / 检验 / 处理 / 特殊处理 / 处置 | **M2 成本端度量** | 回收成本总额（Core-5）、平均单位成本、成本结构占比（5 类） |
| **S3 策略·流转转化** | 让更多入库吨成为"已产出"：提高处理率、压缩未决与在途                         | **M3 转化端度量** | 处理率、未决率、在途率                                     |


**相关性骨架（核心恒等式，M0 与全部 M 的连接线）：**

```
净回收价值 / 入库吨  ≡  ( 平均单位价值 × 处理率 )  −  平均单位成本
     M0                    M1.2         M3.1              M2.2

 代入设计目标值验证：320.00 × 80.00% − 186.00 = 70.00 ✓
```

- 平均单位价值（M1.2）和平均单位成本（M2.2）再各自向下展开驱动比（M1.3~M1.5、M2.3），
- 处理率（M3.1）由快照状态（M3.2、M3.3）解释。
- **指标是否属于本链的判据**：能否写进或解释这个恒等式。不能解释的指标一律移出。

## 2. 北极星与一级拆解

### 2.1 北极星：净回收价值 / 入库吨

- 业务问题：期间内每进入一吨木材，截至现在净赚了多少商业回收价值（核心回收成本之后）？
- 公式：(回收价值总额 − 回收成本总额 Core-5) ÷ 期间入库吨
- 时间基准：**期间**（selected period，2025-01-01 ~ 2025-12-31）
- 口径说明：分子是"**至今累计**"（含积压/未决的已发生成本与已实现价值），分母是"**期间入库**"。
  这是运营管理度量，不是会计利润——短期窗口数值会因成本与产出的时点错位而波动。
- 设计目标值：**70.00 AUD/t**（净额 86,800 AUD ÷ 1,240.0 t）
  - 注：`METRIC_DICTIONARY.md` 中 85.08 AUD/t、旧 seed 20260818 的 69.95 AUD/t 均**已作废**，以本文件（seed 20260820）为准。

### 2.2 一级拆解恒等式

```
回收价值总额（M1.1）   =  Σ 产出重量 × 单位价值        → 317,440.00 AUD（= 320.00 AUD/处理 t × 992.00 t）
回收成本总额（M2.1）   =  Σ Core-5 各类成本             → 230,640.00 AUD（= 186.00 AUD/入库 t × 1,240.0 t）
处理率（M3.1）          =  处理吨 ÷ 入库吨              → 80.00%
净回收价值 / 入库吨     =  317,440.00 ÷ 1,240 − 230,640.00 ÷ 1,240 = 70.00 AUD/t
```

## 3. 一级成分定义

### 3.1 回收价值总额（M1.1）

- 公式：`SUM(RecoveryOutputs.gross_value_aud)`；单位 AUD；时间基准：期间。
- 价值端切片（产出标签维度）：
  - 按等级：Premium 169.09 t @ 648.67 AUD/t ｜ Character 201.49 t @ 443.27 ｜ Rustic 246.59 t @ 279.07 ｜ Feedstock 393.19 t @ 123.17
  - 按路线：Higher-value Recovery 198,994.90 AUD（370.58 t，贡献 62.9% 价值）｜ Board Feedstock 107,941.34 ｜ Special Handling 8,498.82 ｜ Residual/Disposal 803.70

### 3.2 回收成本总额（M2.1，Core-5）

- 公式：`SUM(CostLedger.total_cost_aud)` WHERE 类别 ∈ {Sorting Labour, Inspection, Processing, Special Handling, Disposal}；单位 AUD；时间基准：期间。
- **口径**：与 `METRIC_DICTIONARY` 的 Core-5 一致，**排除 Transport（31,000 AUD）与 Other（5,157.86 AUD）**。
- 当期结构（M2.3）：Processing 102,088.00（44.5%）｜ Sorting Labour 66,931.20（29.2%）｜ Inspection 51,887.87（22.6%）｜ Special Handling 6,186.56（2.7%）｜ Disposal 2,407.31（1.1%）。

## 4. 维度：木头状态标签

### 4.1 两套标签

| 标签                                                                          | 取值                                                   | 用途                   |
| ----------------------------------------------------------------------------- | ------------------------------------------------------ | ---------------------- |
| **状态标签**（`Materials.resolution_status`）                         | Output / Pending Processing / In Progress / Unresolved | 转化端主维度，全链切片 |
| **产出标签**（`RecoveryOutputs.recovery_grade` / `recovery_route`） | Premium~Feedstock / 4 条路线                           | 价值端子维度           |

### 4.2 归属规则（方案 B：状态专属成本强度）★ 2026-08-20 版本化

> 决策来源：`sample_data_design.md` §4.2（用户确认）。替代旧的"批次内按状态重量占比摊分"规则。

- 价值：**只有 Output 状态计入价值**，按产出等级 / 路线归属；其余状态价值 = 0（价值尚未实现）。
- 成本（Core-5）按状态专属强度归属：
  - **Sorting Labour + Inspection**：按状态重量摊分（所有吨都背，率 × 状态吨）；
  - **Processing / Special Handling / Disposal**：**仅 Output**（或其中对应路线吨）承担。
- 推论：非 Output 吨的单位亏损 = Sorting + Inspection 单位率之和（沉没成本）；Output 吨背全栈。
- 该规则为原型口径，落地后建议改为事件级核算；归属规则变更必须版本化。

### 4.3 状态标签 × 净价值矩阵（设计目标值，来源：`sample_data_design.md` §5.3）

| 状态标签 | 重量 t | 归属成本 AUD | 归属价值 AUD | 净贡献 AUD | 每状态吨净 AUD |
|---|---:|---:|---:|---:|---:|
| Output | 992.00 | 206,832.00 | 317,440.00 | **+110,608.00** | **+111.50** |
| Pending Processing | 68.20 | 6,547.20 | 0 | −6,547.20 | −96.00 |
| In Progress | 155.00 | 14,880.00 | 0 | −14,880.00 | −96.00 |
| Unresolved | 24.80 | 2,380.80 | 0 | −2,380.80 | −96.00 |
| **合计** | **1,240.00** | **230,640.00** | **317,440.00** | **+86,800.00** | **+70.00** |

> 旧 seed 20260818 实测值（Output 1,010.35 t / −241.64 等）已作废，以设计目标值为准。

### 4.4 从矩阵读出的相关性结论

- **非 Output 吨固定亏损 96.00 AUD/t**——那是已沉没的分拣+检验成本（54.00 + 42.00）；三个未闭环池合计 248 t，吃掉 23,808 AUD——直接对应 S3 策略空间。
- Output 的 +111.50 AUD/t 是全链的"现金牛"基准，S1 的目标是把它抬高，S3 的目标是让更多吨落到这个池。
- 该矩阵是三条策略的**汇合点**：任何一条策略的指标变化，最终都必须能在矩阵中追到行或列的移动。

## 5. OSM 指标卡

> 每个指标给出：目的归属 / 业务问题 / 公式 / 单位 / 时间基准 / 对北极星的传导 / 状态标签切片。
> 算法细节以 `METRIC_DICTIONARY.md` 为准，此处不重复。

### M0 净回收价值 / 入库吨（北极星）

- 公式：`(M1.1 − M2.1) ÷ 入库吨`；AUD/t；期间；切片：§4.3 矩阵。
- 传导：本身就是 O1 的度量，一切指标最终都要能推导回它。

### M1 价值端（S1）

| 指标              | 公式                                | 单位/基准         | 对北极星的传导                                   | 状态切片                  |
| ----------------- | ----------------------------------- | ----------------- | ------------------------------------------------ | ------------------------- |
| M1.1 回收价值总额 | Σ gross_value_aud                  | AUD / 期间        | M0 分子的正项                                    | 仅 Output 池，按等级/路线 |
| M1.2 平均单位价值 | M1.1 ÷ 处理吨                      | AUD/处理 t / 期间 | 恒等式直接乘数                                   | 按等级：价差决定切片      |
| M1.3 HV 率        | HV 路线重量 ÷ 处理吨               | % / 期间          | HV 池单价远高于 BF 池 → 推高 M1.2               | 按批次/来源切片           |
| M1.4 降级率       | 最终等级 < 初始等级的重量 ÷ 处理吨 | % / 期间          | 降级把吨从高价等级推向低价等级 → 压低 M1.2      | 按等级对切片              |
| M1.5 等级结构占比 | 各等级重量 ÷ 处理吨                | % / 期间          | M1.2 ≡ Σ(等级占比 × 等级单价)，等级单价为参数 | 等级本身就是切片          |

### M2 成本端（S2）

| 指标                        | 公式             | 单位/基准         | 对北极星的传导                                           | 状态切片            |
| --------------------------- | ---------------- | ----------------- | -------------------------------------------------------- | ------------------- |
| M2.1 回收成本总额（Core-5） | Σ 5 类成本      | AUD / 期间        | M0 分子的负项                                            | 按状态摊分（§4.2） |
| M2.2 平均单位成本           | M2.1 ÷ 入库吨   | AUD/入库 t / 期间 | 恒等式直接减项                                           | 按状态摊分          |
| M2.3 成本结构占比           | 各类成本 ÷ M2.1 | % / 期间          | 识别最大的成本杠杆（处理 44.5%、分拣 29.2%、检验 22.6%） | 按状态×类别        |

### M3 转化端（S3）

| 指标        | 公式                                         | 单位/基准 | 对北极星的传导                                         | 状态切片                 |
| ----------- | -------------------------------------------- | --------- | ------------------------------------------------------ | ------------------------ |
| M3.1 处理率 | 处理吨 ÷ 入库吨                             | % / 期间  | 恒等式直接乘数                                         | —                       |
| M3.2 未决率 | Unresolved 重量 ÷ 入库吨                    | % / 快照  | 未决 = 0 价值 + 沉没成本 → 压低处理率                 | Unresolved 池本身        |
| M3.3 在途率 | (In Progress + Pending Processing) ÷ 入库吨 | % / 快照  | 在途 = 成本已付、价值未实现的时间型损耗 → 压低当期 M0 | In Progress / Pending 池 |

**快照口径提醒**：M3.2 / M3.3 是快照指标，只能说明"当下"，不能说明"发生了多少"；
与期间指标（M1、M2）比较时必须标注 `as_of`。

## 6. 指标相关性：传导链与权衡（本体系"为什么这样设计"）

1. **恒等式是骨架**：M0 = M1.2 × M3.1 − M2.2。任何指标改动最终都作用于这三项之一，指标间不存在孤岛。
2. **S1 内部**：HV 率与降级率都作用于等级结构（M1.5），但 HV 率受原料禀赋约束（来源类型决定等级上限），
   降级率才更多受作业质量影响——所以两者并列为驱动，不互相替代。
3. **S2 与 S3 的权衡**：检验成本上升（M2.1↑）通常换来未决下降（M3.2↓）→ 处理率上升（M3.1↑）。
   净效应是正是负，用状态矩阵验证：若检验投入使 Unresolved 行整体变短且 Output 行变长，则 M0 上升。
4. **S1 与 S2 的权衡**：特殊处理（M2.1↑）可能保住本会跌入 Feedstock 的等级（M1.2 不降）。
   只有当"等级价差 × 保住吨数 > 特殊处理成本"时策略才成立——用 §4.3 矩阵逐池核算。
5. **跨期相关性（快照 vs 期间）**：当期快照的在途池（M3.3）会在未来期间转化为 Output 池——
   所以看 M0 时必须区分"本期已实现"与"在途即将实现"，这是 Provisional 口径存在的意义
   （详见 `TIME_SEMANTICS.md` §D：Realised vs Provisional，仅用于批次级比较，不进入状态矩阵）。
